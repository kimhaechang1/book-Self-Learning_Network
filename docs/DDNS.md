## DDNS (Dynamic DNS)

DDNS 는 네트워크 장치의 동적으로 변경되는 IP 주소를 도메인 이름과 자동으로 매핑해주는 서비스

이는 특히 ISP로 부터 `동적 IP 주소`를 할당받는 환경에서 사용된다.

<a href="./DNS와 자원.md">DNS 란?</a>

DDNS는 다음과 같이 작동된다.

1. IP 변경 감지: ISP로부터 새로운 동적 IP 주소를 할당받게 되며, 그 변화를 감지함

2. DDNS 서버로 업데이트 요청 전송: DDNS 서버로 새로 할당받은 IP주소에 대한 변경요청을 보냄

## 그럼 DNS와는?

`DNS`는 `고정IP와 도메인 네임을 매핑`하는 것

`DDNS`는 `동적인 IP 변화`에도 도메인 네임에 `업데이트` 시키는것
